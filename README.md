# Azotea workspace
This workspace hosts a series of projects related to [Citizen Science AZOTEA project](https://guaix.ucm.es/azoteaproject).

Currently, there are these projects, each one installable via pip:
* [azotea-cli](packages/azotea-cli/README.md)
* [azotea-fits](packages/azotea-fits/README.md)
* [azotea-plot](packages/azotea-plot/README.md)
